# Vision · 本站存在的理由

> **Every number about forced displacement — checkable, citable, remembered.**
> **讓每一個被迫流離失所的數字，都能被查證、被引用、被記住。**

## 收斂：一句話與五根柱子

「他們去了哪裡」不是新聞網站、不是倡議平台、不是募款入口。它是一件公共基礎設施：把
UNHCR、IDMC 與聯合國已經公開的統計，變成任何人都能**查證、引用、重現**的形式。五根柱子：

1. **可引用（Citability）** — 固定連結重現一切；引用格式逐字節正確；快照可回溯；（下一步）DOI 永久典藏。
2. **對「計數」誠實（Honesty about counting）** — 未報告≠零；類別的誕生年份標示出來；高報低報的誘因寫在來源旁邊；估計與確認永不混同。
3. **尊嚴（Dignity）** — 永不處理個人資料；衝突座標模糊化；不轉貼敘述、不消費苦難；藍色而非警示色。
4. **持久（Permanence）** — 每份年度快照進版本庫；網站消失，數字仍在;引用五年後仍解析得到。
5. **零成本韌性（Zero-cost resilience）** — 沒有伺服器可以倒、沒有帳單可以逾期;一個人加上自動驗證就能長期維護。

**成功的定義**:出現在論文的方法段、報導的資料出處欄、NGO 簡報的引用列——而不是流量。

## 發散:曾經考慮、然後放下的方向

| 方向 | 為何放下 |
| --- | --- |
| 即時危機追蹤器 | 即時=估計;把估計放在核心會腐蝕「確認數據」的信譽。IDU 因此只是一個明確標示的圖層。 |
| 倡議/請願平台 | 立場會讓引用者卻步。本站的立場只有一個:數字要誠實。 |
| 募款中介 | 經手善款需要的信任基礎完全不同;連結直達組織、承諾永不抽成,反而更有力。 |
| AI 敘事生成 | 生成的文字無法逐字查證,與本站的存在理由矛盾。AI 只維護程式與文件;故事頁的每個數字由資料計算。 |
| 個案地圖 | 紅線:任何個人層級資料都可能危及當事人。永不。 |

## What this means in English

Where They Went is public infrastructure, not a publication: it turns the statistics UNHCR,
IDMC and the UN already publish into a form anyone can **check, cite and reproduce**. Five
pillars — citability, honesty about counting, dignity, permanence, zero-cost resilience.
Success is measured in citations and reuse, never in traffic. Directions considered and set
aside: a live crisis tracker (estimates would corrode the confirmed-data brand — IDU stays a
labelled layer), advocacy (the only stance is honest numbers), donation brokering (links go
straight to organisations, no cut, ever), AI-generated narrative (ungeneratable-from-source
text contradicts the site's reason to exist), and any person-level mapping (the red line).
